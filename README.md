## 怎麼退回舊版（在 Vercel 操作）

1. 登入 https://vercel.com → 點專案 **kinmenportnew** → 上方 **Deployments**
2. 每一筆的說明就是版本（例如「V7：…」），找到要的那一版
3. 點右邊 **⋯** → **Promote to Production**（或 **Instant Rollback**）→ 確認
4. 約 1 分鐘後正式網址就變成那一版；要回到最新版，同樣方式選最新那一筆即可

> 注意：V5 以後的版本都連同一個雲端資料庫，退回舊版時客戶看到的資料是同一份。
